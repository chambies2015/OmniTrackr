Start with the Job You Need Done

A good tracker should make a repeated task easier: finding your next book, remembering where you stopped in a show, or recalling why a film stayed with you. Moving years of history will not help if that everyday task becomes harder.

OmniTrackr brings movies, TV, anime, games, music, and books into one library. That is useful when you move between formats. If a film discussion community or automatic playback logging is the main reason you track, keep that requirement at the center of your choice. You can use OmniTrackr alongside another service without rebuilding your entire history.

Test a Routine Before Moving a History

If you mostly lose track of recommendations

Save three things you might start next, then return a few days later. Can you find them quickly and choose one? In OmniTrackr, Next Up gives a short list a deliberate order. A huge imported backlog is less useful if it hides those three choices.

If you forget where you left off

Try saving an episode or book page in the demo, then look at the checkpoint on that sample title's card. In your own library, recent unfinished checkpoints also appear in Continue. OmniTrackr checkpoints are manual reminders. If you need progress to follow your player automatically, evaluate a compatible Trakt integration instead.

If you want to remember what mattered

Write one sentence about something you finished. Decide whether it belongs in a private journal, a review, or a collection you deliberately share. OmniTrackr separates those choices; the sharing guide explains how to check them.

A useful trial is one ordinary week, not a complete migration. Keep your existing tracker while testing the new routine. Decide which service holds your main record so that two lists do not quietly diverge.

Where OmniTrackr Has Limits

  • No automatic account sync: importing a file is a one-time action. Later changes on Letterboxd, Goodreads, Trakt, or another service do not flow into OmniTrackr automatically.
  • Manual progress: OmniTrackr does not connect to your streaming player to log viewing. Current episode, page, or chapter reminders must be updated by you.
  • A migration is not a full copy of a service: supported CSV fields become library records. Social connections, custom source shelves, likes, and a complete source diary are not recreated.
  • Duplicate matching is simple: the studio checks title and year for movies, TV, and anime; title and release year for games; title and artist for music; and title and author for books. It does not reconcile alternate titles or identify book editions by ISBN.

If those limits remove the feature you value most, keep the specialist tool for that job. OmniTrackr can still hold a smaller selection of favorites, current titles, and next choices across your other categories.

Bring an Existing List with the Import Studio

You do not need to type an existing library again. In Account Settings → Import Studio, a file preview shows what would be added before you confirm. The studio accepts UTF-8 CSV or TSV, up to 5 MB and 5,000 rows per batch.

  1. Keep the original export. Make a working copy for any changes. For a Letterboxd export, extract the ZIP first and choose a supported film CSV from it; do not upload the ZIP. Letterboxd's export page describes the files it provides.
  2. Choose a supported source. The studio understands Letterboxd-style, Goodreads-style, and MyAnimeList-style CSV columns. MyAnimeList XML is not accepted. For a spreadsheet, choose Generic CSV / spreadsheet, select a media category, and map your columns if their names differ. Category templates are available in the studio.
  3. Preview a small batch. Select Preview import. This step does not save records. Inspect ready, duplicate, and invalid rows, including later pages of the results. Check the year, rating, and completion state against your original list.
  4. Check what transfers. Letterboxd and Goodreads adapters double five-point ratings: 3.5 becomes 7/10. Generic CSV ratings already use a ten-point scale. Letterboxd review text and diary visits are not imported; Goodreads review text is supported, but custom shelves and reading dates are not preserved.
  5. Confirm the batch. Confirmation imports all ready rows in that preview, skipping duplicate and invalid rows. Existing records keep their values. Imported review text is not published to public review pages, but friends can read it if you share the category. To import a smaller selection, reduce the file and preview it again.
  6. Check the result in your library. Review the created and skipped counts, open the relevant category, and set any current progress reminders. Download an OmniTrackr JSON backup after you are satisfied with the result.

There is no dedicated IMDb or Trakt adapter. If you have a CSV from another source, use the generic option and check every mapped field in the preview; do not assume its status or rating values have the same meaning. Missing years and different spellings can also prevent duplicate matches.

CSV migration and JSON restore are different. The Import Studio only adds new records. Restoring an OmniTrackr JSON backup can update matching library records. Use the export and import guide for worked examples, matching rules, and backup details before restoring a file.
