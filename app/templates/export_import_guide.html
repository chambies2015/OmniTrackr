Export & Import Guide

Bring an existing media history into OmniTrackr without surrendering control of the library you already built.

Why Data Portability Matters

A personal media library becomes more valuable over time. Ratings, reviews, recommendations, status choices, and cover art represent many small decisions. If that data is trapped in one account with no export path, the tracker becomes risky to rely on.

OmniTrackr includes JSON export and import so users can keep a copy of their own library. That fits the app's privacy model: the collection belongs to the user, and the app should make it practical to back up or move that data.

Portability also helps people try a tracker with less anxiety. If you know your media history can be exported, it is easier to invest time writing better reviews, organizing a backlog, or cleaning up old lists. A good tracker should make your library more useful without making it feel locked away.

What an Export Includes

Exports include metadata about the export itself and lists for movies, TV shows, anime, video games, music, books, and custom tabs. Entries preserve fields such as titles, creators, years, ratings, status values, reviews, public-review choices, poster or cover URLs, and category-specific metadata.

A regular export is useful before major account changes, after large import sessions, or any time a user wants an offline backup of their media history.

  • Core categories: movies, TV shows, anime, video games, music, and books are exported as separate lists so category-specific fields remain understandable.
  • Review context: review text and rating fields travel with the entry, which helps preserve why an item mattered instead of only saving its title.
  • Privacy choices: public-review flags and visibility-related fields are part of the exported data where supported, so restored data keeps important sharing context.
  • Artwork references: poster and cover URLs are included when available, but users should remember those images may come from third-party sources that can change over time.
  • Custom tabs: flexible custom lists are included so specialized collections do not disappear during a backup.

How Import Helps: Two Paths with Different Jobs

OmniTrackr keeps migration separate from backup restoration. The Import Studio accepts CSV or TSV files from another tracker or spreadsheet and only creates records that are not already in your library. JSON restore accepts an OmniTrackr backup and can update matching records because the backup already uses OmniTrackr's own field structure.

That distinction is intentional. A third-party CSV may omit a director, publication year, or release date, so it should never be trusted to replace a richer record you already maintain. The studio classifies matches as duplicates and leaves the existing version untouched.

What the Import Studio Understands

  • Letterboxd: watched, diary, ratings, and watchlist-style CSV columns become movie records. Letterboxd's five-point rating is converted to OmniTrackr's ten-point scale. Watchlist rows remain unwatched.
  • Goodreads: title, author, publication year, shelf status, rating, date read, and review fields become private book records. Goodreads ratings are also converted from five points to ten.
  • MyAnimeList: series title, episode total, score, status, start year, and comments become anime records.
  • Generic spreadsheets: choose one of OmniTrackr's six categories or include a category column. Familiar headings such as title, creator, year, rating, status, review, genre, seasons, episodes, and release date are recognized automatically.

When a spreadsheet uses personal headings such as “Thing,” “Maker,” or “My verdict,” open the optional mapping panel and pair those columns with OmniTrackr fields before previewing. Downloadable templates are available for every built-in category if you would rather copy data into a known layout.

Preview First, Then Decide

  1. Open Account Settings and find the Import Studio.
  2. Select the original service or let OmniTrackr detect it from the headers.
  3. Choose the file and map unusual columns if necessary.
  4. Preview the batch. No database writes happen during this step.
  5. Review ready, duplicate, and invalid totals along with the row-level explanation.
  6. Confirm only when the preview looks right. The exact file and mapping must still match the preview.

The confirmed batch is atomic: all ready rows are created together, or none are created if saving fails. Duplicate and invalid rows remain unchanged. Imported review text is private by default, and the studio does not call external artwork services while processing the file.

Imports are limited to 5 MB and 5,000 rows per batch. This keeps the preview understandable and prevents one accidental export from overwhelming an account. Larger histories can be split into dated or category-specific files.

A Good Backup Habit

  1. Export after adding a large batch of media.
  2. Export before testing a major import file.
  3. Keep dated copies so you can return to an older state if needed.
  4. Store backups somewhere separate from the browser or device you use every day.
  5. Review imports before assuming every record matched exactly as expected.

A simple naming pattern helps too. For example, use a date in the filename so you can tell which backup came before a major cleanup or import. If you keep multiple backups, keep the newest copy and at least one older copy from before big changes.

What to Remember About Backups

An export is a useful copy of your library data, but it is not a replacement for account security. Keep your password safe, verify your email, and store backup files somewhere only you can access. JSON files are readable data files, so treat them like personal documents if they include private reviews, ratings, or notes.

Exports are also snapshots. If you add ten new reviews after downloading a file, those new reviews are not inside the old export. Download another backup after meaningful changes, especially after updating public review choices or finishing a large backlog cleanup.

Why This Matters for Choosing a Tracker

Media trackers become part of a routine. People use them to remember recommendations, decide what to start next, revisit favorites, write annual summaries, and compare ratings across categories. Export and import are important because they lower the risk of building that history in one place.

OmniTrackr is designed around the idea that useful tracking should still be portable. You can organize your library, write private or public reviews, use statistics, and share selectively with friends while still keeping a backup path for your own records.
